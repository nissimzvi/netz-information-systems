# נץ מערכות מידע

אתר תדמית סטטי בעברית, מוכן ל-GitHub Pages.

## קבצים
- `index.html` — דף הבית
- `about.html` — אודות
- `services.html` — מה אני עושה
- `cio.html` — CIO במיקור חוץ
- `contact.html` — צור קשר
- `styles.css` — עיצוב רספונסיבי RTL
- `script.js` — תפריט מובייל וטופס WhatsApp
- `assets/nissim-zvi.jpg` — תמונת ניסים

## פרסום ב-GitHub Pages
1. צור Repository חדש בשם `netz-information-systems`.
2. העלה את כל הקבצים לשורש ה-Repository.
3. Settings → Pages.
4. תחת Build and deployment בחר `Deploy from a branch`.
5. Branch: `main`, Folder: `/ (root)` ולחץ Save.
